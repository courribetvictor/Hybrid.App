# Hybrid.App 0.6.0 — V6 Polish & Immersion

Cette version n'empile pas des fonctionnalités : elle améliore le feeling global.

- interactions tactiles animées (`SensoryPressable`)
- sons/haptics unifiés et configurables
- lancement Hybrid court et animé
- transitions Stack / modales plus naturelles
- barre d'onglets flottante et tactile
- Accueil Today révélé progressivement
- Hybrid Score en count-up
- readiness en anneau
- skeletons de chargement du feed
- fiches activité directement ouvrables
- récompenses avec halo + particules + son + vibration
- grade avec glow subtil
- radar et leaderboard animés
- écran Sensations avec aperçu de récompense
- succès/erreur de sauvegarde harmonisés
- `.gitignore` sécurisé pour GitHub
- scripts `npm run typecheck` et `npm run doctor`
- checklist Pull Request GitHub

Aucune migration Supabase supplémentaire n'est nécessaire : V6 utilise le schéma V5.
